# Weather file

Put an EnergyPlus `.epw` weather file here as `site.epw`.

Free weather files for any location: https://energyplus.net/weather

For the hackathon, the fastest path is to reuse whichever `.epw` ships in
your EnergyPlus install's `WeatherData/` folder (e.g.
`USA_CO_Golden-NREL.724666_TMY3.epw`) — no need to hunt for a site-specific
file unless the brief requires it.
